# Security

The current supported preview is 1.2.x. Report potential vulnerabilities through this repository's private vulnerability reporting feature when available. Do not disclose user documents, paths, tokens or exploit details in public issues. If private reporting is unavailable, request a private reporting channel without disclosing the vulnerability itself.

Include the affected version, impact, a minimal synthetic reproduction and any proposed fix. There is no guaranteed response time or bug bounty.

Markdown is sanitized with DOMPurify. The Windows host restricts navigation and file access to validated document-relative paths. The app registers a candidate file handler; Windows retains control of default choices. Keep these boundaries intact.
